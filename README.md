# TrueMark Public Monorepo

## Structure

- `autoalarm` - Tag-driven CloudWatch alarm automation for AWS resources.
- `autobackup` - Tag-based automated backups using AWS backup.
- `autostate` - Tag-driven start, stop, reboot and terminate scheduling for AWS resources.
- `database-collector` - Tag-driven collection of additional database metrics over JDBC.
- `cdk` — TrueMark CDK Library available on [npmjs.com](https://www.npmjs.com/package/truemark-cdk-lib)
