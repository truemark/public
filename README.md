# TrueMark Public Monorepo

## Structure

- `autoalarm` - Tag-driven CloudWatch alarm automation for AWS resources.
- `autobackup` - Tag-based automated backups using AWS backup.
- `autostate` - Tag-driven start, stop, reboot and terminate scheduling for AWS resources.
- `cdk` — TrueMark CDK Library available on [npmjs.com](https://www.npmjs.com/package/truemark-cdk-lib). Built with jsii for use from other languages.
- `cdk-extra-js` — TypeScript and JavaScript only constructs that cannot be offered through jsii.
